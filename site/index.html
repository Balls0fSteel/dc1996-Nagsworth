Activity tracker + break nagger

A polite butler for your PC.

Nagsworth keeps a note of your hours (apps, games, websites) and clears his throat when it is time for a break. Think of a modern, app-aware Workrave that also knows how long you have been gaming.

What it does

Tracks your time

Which app is in front and for how long, with idle, lock and sleep detection. Steam, launcher folders and a list of known games tell gaming apart from work; your own categories do the rest.

Knows your websites

A small browser extension reports the active tab to the app on your machine, so web time shows per site. A toolbar popup shows today's top sites and your rules' progress.

Nags like Workrave, only smarter

Interval breaks and micro-breaks, reading mode, daily limits per category ("2 h of gaming"), continuous-use limits and schedules ("no gaming 23:00–06:00").

Counts hands-on time

A gaming limit burns only the seconds after a key press, mouse move or controller input. Two hours in front of a game with one hour of actual play costs one hour of the budget.

Fills the break

Each break suggests exercises that fit its length and how long you have been sitting: a walk, neck work, eye breaks, breathing. 28 items, each with the evidence behind it, rotated so routines vary. Not medical advice.

A dashboard worth opening

Today, History, Apps, Web, Rules and Settings in one window from the tray. Rules are TOML, editable in the app, validated and applied without a restart. Export to CSV or JSON any time.

Escalation, politely

Each rule climbs a ladder you choose. Ignore the butler long enough and he stops whispering.

  1. 1

    Toast

    A small card in the corner with the reason, a countdown and buttons to start the break, snooze or skip.

  2. 2

    Overlay

    A fullscreen overlay on every monitor with the break's exercises, step by step. It waits if a game is in exclusive fullscreen.

  3. 3

    Lock (opt-in)

    Locks the workstation with the operating system's own lock. Off in the shipped rules; you turn it on per rule.

# config.toml: two hours of gaming a day
[[rules]]
id = "gaming-daily"
name = "Gaming limit"
scope = { category = "Game" }
trigger = { kind = "daily_total", limit = "2h", renag_every = "15m" }
escalation = [ { after = "0s", level = "toast" },
               { after = "10m", level = "overlay" } ]

Everything stays on your machine

Nagsworth is a tool for you, about you, on your own PC. Nothing is sent anywhere.

  • One SQLite file in your user folder (%LOCALAPPDATA%\nagsworth, ~/.local/share/nagsworth).
  • A local API bound to 127.0.0.1 with a bearer token; the extension pairs with a code you read off the dashboard.
  • No global hooks, no injection, no reading other processes' memory. It polls documented OS APIs, which keeps antivirus tools calm.
  • Your data, your formats: CSV/JSON export and database backups from Settings.
  • The only network call is an optional update check against this project's GitHub releases, which you can switch off.

Where it runs

Windows

Tray app with an installer that updates itself: it downloads the new setup, checks it against the release's SHA256SUMS and restarts in a few seconds. Controller input through XInput.

Linux

.deb and AppImage. EWMH on X11 and XWayland, wlr-foreign-toplevel on Sway and Hyprland, lock and sleep from systemd-logind. GNOME on Wayland hides the focused window, so only X clients are tracked there.

Browsers

Chrome 102+, Edge, Brave, Opera, Vivaldi and Firefox 140+. The extension talks only to the app on 127.0.0.1 and can forget everything with one button.

Build from source

Needs Rust 1.90+, Node 20.19+ and, on Windows, WebView2.

git clone https://github.com/Balls0fSteel/dc1996-Nagsworth
cd dc1996-Nagsworth
npm install
npm --prefix ui install
npm --prefix extension install
npm run tauri dev
